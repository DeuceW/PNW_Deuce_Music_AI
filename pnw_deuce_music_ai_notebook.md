# PNW DEUCE MUSIC AI NOTEBOOK

`pnw_deuce_music_ai.py` is the authoritative implementation. `SKILL.md` (when distributed with the reusable skill) is the specification authority.

## Pipeline

`validated request -> frozen Pydantic SongPlan -> deterministic theory/drum/bass/melody plans -> canonical mido Type-1 MIDI exporter -> explicit rendering`

## Canonical MIDI contract

`export_mido_midi(plan)` is the only supported MIDI exporter. It creates a Type-1 `mido.MidiFile` at 480 PPQ with Conductor, Drums, 808, and Melody tracks. The old custom standard-library byte serializer is deprecated and must not be reintroduced as a competing path.

## Determinism

All randomness is from an explicit `random.Random(seed)`. Pitch classes use the `PITCH_CLASS` table and integer arithmetic. Python's process-randomized `hash()` is prohibited. Tests launch fresh subprocesses with multiple `PYTHONHASHSEED` values and compare plan JSON plus mido-generated bytes.

## Validation

Pydantic v2 frozen models enforce the intent-layer boundary. Invalid types and mutations are rejected. Audio headroom and normalization behavior belong to explicit rendering utilities and are not silently applied by MIDI export.
